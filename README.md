# Custom 404 Error Page

This repository contains a clean and modern **Custom 404 Error Page** built using HTML, CSS, and optional JavaScript for animations.  
It is fully responsive and can be used on any website hosted on GitHub Pages, GoDaddy, Hostinger, or any Apache-based server.

## Features
- Fully responsive UI
- Clean and modern design
- Lightweight and fast
- Works on all browsers
- Easy to integrate into any project

## What This Project Includes
- `404.html` — Main error page  
- `/css/404.css` — Styling for the page  
- `/assets/` — Images or illustrations used  
- `/js/404.js` — Optional animations or interactions  

## How to Use

### For GitHub Pages
1. Upload `404.html` to the root of your repository.
2. GitHub Pages will automatically serve it for missing routes.
